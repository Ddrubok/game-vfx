# 피드백 수정

[English](feedback-repair-2026-11-05.md) | [한국어](feedback-repair-2026-11-05.ko.md)

기준일: 2026-11-05. 로컬 지침과 예제를 수정했으며 새로운 에이전트 비교 실험은 수행하지 않았습니다.

## 변경

- 종료된 일회성 효과는 높은 revision도 거절하며, 소유자 세대 토큰으로 옛 완료 콜백이 재사용된 효과를 종료하지 못하게 했습니다. 선택적 어댑터와 렌더링 재생 예제로 구현했습니다. 거절·만료 시 수명을 닫는 것은 이 예제의 정책이며 보편적인 서버 프로토콜은 아닙니다.
- 첫 내보내기 프레임은 0.02초에서 표본을 얻고, 재생은 여전히 0초에서 시작해 20장 × 40ms입니다. `timeSeconds`는 재생 위치, `sampleTimeSeconds`는 시각 표본입니다. 마지막 0.78초 표본은 8비트 정밀도에서 투명하지만 해당 장의 40ms는 유지합니다. 렌더러의 빈 시작·종료 시점은 바꾸지 않았습니다.
- 이식 가능한 Canvas 검사기, 엔진 판별, 기존 3D 소스 연결, Godot 가져오기 참조 코드, 메모리·시간 조사 방법을 공개했습니다. Godot 코드는 **미실행**입니다.
- 직접 전달과 bettermakegame 경유 전달 문구, 조건부 참조 순서, 오래된 게시 표기를 수정했습니다. 과거 결과와 해시를 새로운 성공 기록으로 대체하지 않았습니다.

추가 검사 초기에 소수 시간 누적의 종료 경계(`0.1 + 0.7`) 문제와 모든 페이드 프레임이 보여야 한다는 과도한 검사 조건을 발견했습니다. 종료 경계는 부동소수점 정밀도 보정·회귀 검사로 수정했습니다. 내보내기 검사는 실제 요구인 **첫** 프레임 표시를 확인하고 마지막 페이드가 투명하다는 결과도 공개합니다. 위 표는 수정 후 실행입니다.

최종 프레임 모음·밝은 배경·정정 중 장면을 이미지 도구로 열었습니다. 정지 화면 확인과 자동 재생 검사이며 사람의 움직임·선호 평가는 아닙니다. 근거와 소스 해시는 [결과](feedback-repair-2026-11-05-results.json)와 [스냅샷](feedback-repair-2026-11-05-snapshot.json)에 있습니다.

## 남은 한계

- Godot 4.4.1 결과는 사용자 제공 관찰이며 자체 재실행이 아닙니다. PATH와 확인한 일반 설치 폴더에서 적합한 엔진 실행 파일을 찾지 못했습니다. 가져오기·파싱, 0.75초 종료, 네이티브 점/궤적 모습은 미실행 또는 미해결입니다. 해당 관측의 프로젝트·가져오기 설정도 확보하지 못했습니다.
- 2560×2048 RGBA8은 밉맵 전 20 MiB, 전체 밉맵 포함 약 26.7 MiB라는 산술값입니다. GPU 실측치나 보고된 28 MB의 확정 원인이 아닙니다. [엔진 안내](../references/engine-adapters.md)와 공식 출처를 참고하세요.
- 가산 합성, 추가 아트 스타일, 네이티브 엔진 연동, 3D 렌더러는 추가·재검사하지 않았습니다. 단일 source-over 충격파가 당시 예제 범위이며 모든 엔진 지원을 약속하지 않습니다.
- 새 스타일·이벤트·연계 에이전트 행동, 사람 플레이테스트, 실기기·실네트워크, kill-game-slop U/V는 **미실행**입니다. 예제의 정확성은 스킬 출력 개선을 입증하지 않습니다.
