# Godot sheet playback

[English](README.md) | [한국어](README.ko.md)

This optional project imports actual PNG/custom JSON exports from `assets/canvas-impact.html`: radial impact, directional ribbon slash and looping rising embers. It uses imported Texture2D resources, AtlasTexture regions and AnimatedSprite2D. It is a native test scene, not a shipped-game integration or universal JSON importer.

## Run

Use an installed Godot 4. The recorded run used **4.4.1.stable.official.49a5bc7b6**, Windows, GL Compatibility, RTX 3080 Laptop GPU. From the repository root, replace `godot` with the installed executable when needed:

```sh
godot --version
godot --headless --path examples/godot-sheet --editor --import --quit
godot --path examples/godot-sheet --rendering-method gl_compatibility -- --output=/absolute/path/to/evidence
```

The import command is nonvisual. The third command renders, saves `results.json` and `godot-effects.png`, then exits nonzero on failure. Open the saved PNG to inspect appearance. Default output is `user://verification`; choose a writable path. Add `--interactive` after `--` to leave the scene open: one-shots still finish and embers continue.

## Contract and limits

Since v0.4.1, the checker rejects 24 malformed metadata cases while preserving live configuration. Timing checks three warmed trials per one-shot, metadata duration sums and ordered frames. Tolerance is twice the observed maximum frame interval plus 2 ms; an interval above 25 ms fails separately. Headless results do not establish rendered appearance. The v0.4.0 timing figures below are historical.

- JSON `durationMs` maps to SpriteFrames relative durations at the declared FPS; loop flags and pivot are preserved. Midpoint sample time is distinct from playback time.
- Finish hides the one-shot; replay restarts; cancellation stops/hides. Removing one owner leaves the other effect alive. No server/correction protocol is included.
- Historical v0.4.0 warmed native finish signals were **0.582783 / declared 0.6 s** and **0.382836 / declared 0.4 s**. That historical assertion permitted absolute error below **0.10 s**: a coarse regression check, not frame-accurate certification. Another project's 0.75/0.8 s discrepancy remains unexplained.
- Input is trusted bundled-exporter metadata, not hostile arbitrary JSON. Include `*.json` in export filters when packaging; **exported build NOT RUN**.
- Source-over alpha, 128 px frames. Native particle recreation, Android/iOS, Unity/Unreal, player preference and measured GPU memory are NOT RUN.

These assets were generated by this repository's own renderer under MIT. Godot is not bundled. See [results, hashes and captures](../../docs/practical-validation-2026-11-05.md).
