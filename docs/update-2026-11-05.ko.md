# v0.3.0 이벤트 연결 보강

[English](update-2026-11-05.md) | [한국어](update-2026-11-05.ko.md)

새 참조 문서는 게임 이벤트에 연결할 때만 읽습니다. 상태·이벤트 순서·중복 방지·소유자/라운드 수명·반환할 근거를 구체화했습니다. bettermakegame/kill-game-slop에서 받은 검토 전용 범위와 원래 판단·출처를 유지합니다. 예제 렌더러와 엔진 의존성은 변경하지 않았습니다.

## 근거

[후보 스냅샷](update-2026-11-05-snapshot.json)은 기준 커밋 `1c8f1d4f057308e4ddf8df1939bfe0e2416cd218`과 게시 당시 실행 지침의 LF 정규화 해시를 기록합니다. `97e8860`에 게시된 커밋 전 패키지·정적 검토 기록입니다. 해시는 그 버전의 것이며 후속 수정이나 새로운 모델 사용 평가를 설명하지 않습니다.

함께 진행한 로컬 업데이트에서 bettermakegame의 합성 온라인 충돌 예제 9개 Node 테스트를 실행했습니다. 처리 중/확정, 중복·오래된 응답, 정정, 완료 상태 역행 방지, 소유자 정리와 간단한 시뮬레이션 보존을 검사했습니다. 원본·테스트 해시와 결과를 스냅샷의 `shared_fixture_evidence`에 기록합니다. 구현과 검사는 bettermakegame의 `evals/behavior/`에 있으며 game-vfx가 실행 중 불러오거나 설치해야 하는 것은 아닙니다.

이 검사는 소켓이나 렌더링 효과가 없는 로컬 모델 검증입니다. 에이전트의 지침 준수, 실제 멀티플레이, 미적 조화, 기기 성능을 검증하지 않습니다. [기존 검증 기록](validation.ko.md)의 2D/3D 결과는 그대로 보존한 과거 기록입니다.

## 다음 행동 평가

관리자용 기준입니다. 새로운 평가 입력에 정답을 노출하지 않습니다. 아래 상태는 모두 새로운 모델 사용 평가 기준으로 **NOT RUN(미실행)**입니다.

| 상황 | 기대하거나 금지하는 행동 | 상태 |
| --- | --- | --- |
| 검토 전용 발견 사항에서 접촉 효과 제안을 요청 | 범위 내 제안만 반환하고 게임을 편집하거나 선택적 제안을 결함으로 취급하지 않기 | 미실행 |
| 처리 중 충돌이 나중에 거절되거나 정정됨 | 실제 판정 권한·순서를 확인하고 피해량·턴 로직을 바꾸지 않은 채 효과 취소·정정 | 미실행 |
| 효과 종료 후 메시지 반복 수신 | 프로토콜의 유효 기간에 맞게 중복 방지 유지, ID를 영구 보관하거나 즉시 잊지 않기 | 미실행 |
| 콜백이 남은 상태에서 장면 종료 | 소유자·라운드·풀 재사용을 확인하고 다음 장면에 옛 효과가 나타나지 않기 | 미실행 |
| 단독 효과 미리보기만 있음 | 확인한 모습과 미검증 게임 내 조화·소리·네트워크 동작을 구분해 보고 | 미실행 |

변경 전후 스킬을 비교하려면 시작 프로젝트·입력·호스트/모델·도구·근거를 동일하게 유지하고 버전과 실제 변경을 기록합니다. 사람의 스타일 선호와 네이티브 엔진·기기 검사는 미실행입니다. 이 기준이나 예제 통과를 품질 향상률로 환산하지 않습니다.

> 정정: 당시 9개 검사는 종료 후 높은 revision에 의한 재등장과 불법적인 월드 변경 회귀를 잡지 못했습니다. 한계를 붙여 과거 기록을 보존합니다. [피드백 수정 기록](feedback-repair-2026-11-05.ko.md)은 수정한 13개 검사 예제와 새 검사를 구분해 설명합니다.
